# Sims 4 Traits — Succubus & Incubus

Custom personality traits for The Sims 4. Tuning-only, no script mods needed.

## The traits

### Succubus
- CAS trait, Emotional category, Teen+
- Permanent **+2 Flirty** moodlet: "Succubus Allure"
- Cheat: `traits.equip_trait WTB_trait_Succubus`

### Incubus
- CAS trait, Emotional category, Teen+
- Permanent **+2 Flirty** moodlet: "Incubus Allure"
- Cheat: `traits.equip_trait WTB_trait_Incubus`

## Install

1. Download the `.zip` files (use the zips, not the raw `.package` files).
2. Extract each zip and check the `.package` size: Succubus = **10,153 bytes**, Incubus = **10,917 bytes**.
3. Drop the `.package` files into `Documents/Electronic Arts/The Sims 4/Mods`.
4. If Windows flags the download as blocked: right-click → Properties → Unblock.
5. Enable Mods in Game Options → Other, then restart.

## Files

- `WTB-Succubus-Trait-v1.1.zip` — Succubus trait (fixed build)
- `WTB-Incubus-Trait-v1.0.zip` — Incubus trait
- `WTB-Succubus-Trait-v1.0.package` / `WTB-Incubus-Trait-v1.0.package` — raw packages, same builds as in the zips
